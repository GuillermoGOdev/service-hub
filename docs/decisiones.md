# Decisiones de implementación

1. **Angular 20.3.33 y TS 5.9.3.** La PC2 tiene precedencia sobre el esqueleto Angular 22. Paquetes framework, CLI, builder y compiler fijados al mismo parche disponible. Node 24 está en el rango de [compatibilidad oficial](https://angular.dev/reference/versions). Builder application, zoneless explícito y pruebas independientes.
2. **JSON Server 0.17.4 módulo.** [Documentación estable](https://github.com/typicode/json-server/tree/v0.17.4). El router es el CRUD real y escribe db raíz; extensiones acotadas para reglas que cruzan colecciones. No se mezcla API beta ni un segundo almacenamiento. Una instancia, bloqueo cooperativo y tests temporales.
3. **Desactivar cascada implícita.** La suite detectó eliminación de historial relacionada con IDs opcionales. Se cambió foreignKeySuffix y se gestionan referencias en las acciones. No confiar en JSON Server como integridad relacional.
4. **Bootstrap 5.3.8 + CSS propio.** Cumple biblioteca de rúbrica conservando identidad. [Variables oficiales](https://getbootstrap.com/docs/5.3/customize/css-variables/). Se usan clases reales y componentes propios; Angular es dueño de overlays/DOM. Aceptada una advertencia de tamaño inicial, no ocultada elevando el presupuesto.
5. **Inter local y recursos originales.** Offline tras instalar; logo/collage/ilustraciones originales. Medidas concretas de Figma y aproximaciones identificadas en UI. Portadas seed ilustradas quedan explícitamente provisionales.
6. **Cuenta con capacidad profesional.** providerEnabled se habilita con validación backend; no roles mutuamente excluyentes. Conversación única por pareja y contexto histórico por mensaje para soportar cambio de participación.
7. **Dinero y snapshots.** Céntimos enteros, total del servidor, alcance/precio preservados al contratar. Extras una vez por pedido; oferta cantidad uno. Reseña permitida también tras cancelación iniciada. Trabajo y pago separados.
8. **Sesión local y permisos.** Cookie HttpOnly + scrypt; no OAuth ni tarjetas. Router público restringido, validación de propietario/participante y archivos privados. No se afirma seguridad de producción.
9. **Catálogo en memoria desde HTTP.** Dataset pequeño; búsqueda sin tildes y recomendación por afinidad se aplican antes de páginas. API mantiene paginación real 0.17.4, comprobada por integración. No se filtra una sola página remota fingiendo un total global.
10. **Vitest externo, TestBed JIT.** Se retira el target de test generado por CLI 22. El runner invoca TestBed/BrowserTestingModule con configuración propia. No usa el builder experimental de tests de Angular. Las pruebas de API usan node:test y E2E Edge/Playwright.
11. **Correcciones de dependencias detectadas por instalación limpia.** Se fijaron Multer 2.4.0, concurrently 9.2.5 y Vitest 4.1.11. Overrides explícitos de `@angular/build → piscina 5.3.2`, `@angular/cli → @modelcontextprotocol/sdk 1.31.0`, y del peer opcional Vitest de build al runner raíz. Mantiene Angular 20.3.33 alineado sin `audit fix --force`; el runner independiente se verifica por ejecución. Estas excepciones deben reevaluarse al actualizar Angular, no ampliarse indiscriminadamente.

El repositorio conserva la rama original y no tiene commit/push de esta implementación. La documentación describe trabajo existente y pruebas, separando mejoras futuras en Estado actual.
