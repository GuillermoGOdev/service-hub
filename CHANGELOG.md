# Changelog

## 0.1.0 · 2026-10-12

- Migración controlada desde el esqueleto Angular 22 a Angular 20.3.33 y TypeScript 5.9.3; instalación reproducible y comandos Windows.
- Integración del router JSON Server 0.17.4, db raíz y semilla de 18 servicios; permisos, sesiones, perfiles, archivos y reglas de contratación.
- Sistema visual Bootstrap personalizado con Inter local, logo/collage/ilustraciones del usuario y medidas obtenidas de Figma.
- Recorridos de catálogo, editor, listas, chat, ofertas, pedidos, reseñas y CSV; pipe de soles, directiva de foco/hover y feedback con NgIf.
- Pruebas unitarias, API y Edge aisladas; capturas, matriz de cumplimiento y documentación PC2.
- Protección frente a cascadas implícitas de JSON Server sobre relaciones opcionales; bloqueo cooperativo de base y auditoría no destructiva de archivos.

Consultar `docs/estado-actual.md` para limitaciones de esta versión.
